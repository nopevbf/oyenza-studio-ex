# Oyenza Studio v1.3.1

**Full-Screen Volume, Mute & Brightness HUD Fix, and Enabled by Default:**

- **Full-Screen HUD Overlay Fix:** Dynamic Island volume, mute, and brightness HUD overlays now cleanly appear above full-screen apps and games (YouTube F11, media players, and borderless/exclusive games).
- **Enabled by Default:** The `hud_in_fullscreen` setting now defaults to `true`, providing immediate feedback on volume and brightness adjustments in full-screen without manual configuration.
- **Efficient Transient Window Reveal:** When a HUD event triggers during full-screen, the window is temporarily raised topmost and displayed, then immediately returns to complete rest (`SW_HIDE` with 0 CPU cycles) once the HUD expires after 1.6 seconds.

**Install:** Download `Oyenza-Studio-Setup-1.3.1.exe` (or the MSIX package) and run it. It installs per-user (no administrator rights needed) and can start with Windows.
