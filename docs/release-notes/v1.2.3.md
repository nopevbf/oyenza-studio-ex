# Oyenza Studio v1.2.3

**Media Foundation & WASAPI Privacy Sensors, Visual Glow Refinement, and Automated Update Feed:**
- **Advanced Camera & Mic Sensor Detection:** Integrated Windows Media Foundation (`IMFSensorActivityMonitor`) for instant hardware camera streaming detection and Core Audio WASAPI capture session notifications (`IAudioSessionNotification` / `IAudioSessionEvents`) alongside registry notifications. Guarantees immediate zero-latency camera and mic status updates across external webcams, audio interfaces, OBS, browsers, Zoom, and Teams with zero CPU overhead at rest.
- **Refined Privacy Dot Glow & Positioning:** Polished the privacy dot placement on the right edge of the Island with a subtle 5px outer radial glow and 3px crisp core dot.
- **Automated Update Feed CI/CD & Safeguards:** Integrated automated generation and cryptographic signing of `site/latest.json` on release publish in GitHub Actions, backed by built-in test suite (`update_feed_tests.rs`).

**Install:** Download `Oyenza-Studio-Setup-1.2.3.exe` and run it. It installs per-user (no administrator rights needed) and can start with Windows.
