# Oyenza Studio v1.2.2

**Dynamic Notch Battery Contour and External Webcam/Mic Detection Fix:**
- **Dynamic Notch-Following Battery Indicator:** Upgraded the battery indicator from a rigid flat 2D rectangle to a fluid, organic path that dynamically conforms to the notch's bottom curvature (`Seg::ArcTo` bottom-left curve, `Seg::LineTo` base, and `Seg::ArcTo` bottom-right curve). Uses Direct2D rounded stroke caps and precise boundary inset so the line hugs the bottom of the island cleanly without pixel clipping.
- **External Webcam & Microphone Sensor Detection Fix:** Enhanced Windows CapabilityAccessManager ConsentStore evaluation to detect active sensor sessions where `start_time > stop_time` (standard for external USB webcams and desktop conferencing apps like Chrome, Zoom, OBS, Discord, and Teams that don't zero `LastUsedTimeStop`). Added `REG_NOTIFY_CHANGE_NAME` notification monitoring so newly registered subkeys awaken the privacy watcher immediately.
- **Quality & Stability:** Verified with ISTQB standards and comprehensive unit & regression test suites across the workspace.

**Install:** Download `Oyenza-Studio-Setup-1.2.2.exe` and run it. It installs per-user (no administrator rights needed) and can start with Windows.
