**Connectivity Toasts for Bluetooth, Wi-Fi, and Ethernet.** Oyenza Studio now shows a living notch notification whenever a connection changes:
- **Bluetooth:** Shows the device name and battery percentage with a thin blue progress ring and animated double pulse rings for headphones, earbuds, speakers, gamepads, mice, and keyboards.
- **Wi-Fi & Ethernet:** Shows network SSID or "Ethernet" with smooth double pulse rings when connected, and a soft red notice with the offline icon when disconnected.
- **Clean design:** Dark capsule with no cluttering discs, subtle drop shadows, and 40×40 px stable icon areas.

Everything new in 0.2.13 is here too: automatic hourly update checks, Check for updates… in the menu, and lyrics stability. See the [0.2.13 notes](https://github.com/lucacadalora/oyenza-studio/releases/tag/v0.2.13).

**Install:** download `Oyenza-Studio-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`. Links to `Oyen-Poni-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Oyenza-Studio-Mac.dmg` and drag Oyenza Studio into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading:** on 0.2.6 to 0.2.13, the island says **Update available** within a few hours; **Install now** in the Update sheet installs it for you. Or run the new installer. Either way it upgrades in place and keeps your settings, data, add-ons and Oyenza sign-in.

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
