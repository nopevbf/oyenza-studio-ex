# Oyenza Studio v1.1.0

**Connectivity Toasts for Bluetooth, Wi-Fi, and Ethernet.** Oyenza Studio now shows a living notch notification whenever a connection changes:
- **Bluetooth:** Shows device name and battery percentage with a thin progress ring and animated pulse rings for audio devices, gamepads, mice, and keyboards.
- **Wi-Fi & Ethernet:** Shows network SSID or "Ethernet" with smooth double pulse rings when connected, and a soft notice with the offline icon when disconnected.
- **Clean design:** Dark capsule with subtle drop shadows, 40×40 px stable icon areas, and Zero Cost at Rest (2.5s debounce hysteresis, virtual adapter filtering, and pause on lock).
- **Settings Toggle:** Easily toggle connectivity toasts on or off in Settings.

**Task Inline Editing & Daily Progress:**
- **Inline Editing:** Edit any task in place by clicking the edit icon on hover. Save with Enter or the check button, cancel with Esc. Empty inputs automatically revert safely to the original text.
- **Daily Counter Badge:** Top row counter shows "X/Y Task done today" with a mini progress ring.
- **9:00 PM Daily Reminder:** Get a gentle chime sound and island pill notification at 21:00 if you have pending tasks created today. Clicking the pill opens directly to the Tasks page.

**Independent Repository & Update Feed:**
- Built and released from [nopevbf/oyenza-studio-ex](https://github.com/nopevbf/oyenza-studio-ex).
- Automatic in-app updates verified via SHA-256 directly from repo releases.

**Install:** Download `Oyenza-Studio-Setup-1.1.0.exe` and run it. It installs per-user (no administrator rights needed) and can start with Windows.
