# Oyenza Studio v1.2.4

**Discord Support in Notifications, Automated MSIX Packages on GitHub Releases, and Listener Improvements:**
- **Built-in Discord Notification Support:** Added native support for Discord desktop notifications to the dynamic notch island. Discord is now automatically enabled by default (`starts_on = true`) with its signature Blurple accent color (`#5865F2`), displaying sender and message details for 8 seconds.
- **Automated MSIX Release Packages:** Updated the CI/CD pipeline (`store.yml`) to automatically build and attach Microsoft Store MSIX packages (`Oyenza-Studio-1.2.4.msix`) and self-signed, one-click test copy bundles (`Oyenza-Studio-1.2.4-test-copy.zip`) directly to GitHub Releases.
- **Improved Notification Listener Initialization:** Refined WinRT `UserNotificationListener` initialization logic to opportunistically acquire Windows notification listener access across packaged and developer builds.

**Install:** Download `Oyenza-Studio-Setup-1.2.4.exe` (or the MSIX package) and run it. It installs per-user (no administrator rights needed) and can start with Windows.
