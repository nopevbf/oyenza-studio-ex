# Oyenza Studio v1.3.0

**Windows OSD & Toast Suppression, Brightness HUD, and Appearance Idle-Look-Only Mode:**
- **Windows Volume & Brightness OSD Suppression:** Automatically suppresses the distracting native Windows flyout OSDs when volume or brightness keyboard shortcuts are pressed, replacing them with Oyenza's lightweight, hardware-accelerated Volume and Brightness Island HUDs.
- **New Brightness Island HUD:** Introduced a sleek brightness indicator on the dynamic island with the new Sun icon, smooth bar gliding animation, and exact percentage readout. Supports both laptop internal panels (WMI/ACPI) and external desktop displays (DDC/CI via DXVA2) via non-blocking asynchronous workers (Rule 1).
- **Windows Toast Notification Banner Suppression:** Silences floating toast popups from third-party apps (WhatsApp, Discord, Slack, etc.) from cluttering your screen, while ensuring all notifications are still preserved in Windows Action Center / Notification Center history.
- **Appearance "Idle Look Only" Mode:** Added a master toggle under Settings > Appearance to mute all internal island active notices (music track changes, calendar events, prayer/adzan countdowns, downloader, etc.), locking the island strictly in its clean, peaceful idle look.
- **Fail-Safe & Resilient Architecture:** All suppression mechanisms operate purely in user-space without UAC prompts and restore system settings cleanly on exit (Rule 2). Includes UIPI-aware graceful fallback when Administrator windows (e.g., Task Manager) are in focus (Rule 3).

**Install:** Download `Oyenza-Studio-Setup-1.3.0.exe` (or the MSIX package) and run it. It installs per-user (no administrator rights needed) and can start with Windows.
