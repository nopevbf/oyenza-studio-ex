# Oyenza Studio v1.2.1

**Privacy Indicators, Dynamic Eyes & Glove Wave, and Battery Status Line:**
- **System-Wide Camera & Microphone Privacy Indicators:** An event-driven privacy dot appears on the right edge of the Island whenever any Windows app uses your camera (Emerald Green `#4ADE80`) or microphone (Amber Orange `#FB923C`). Camera takes priority if both are active simultaneously. Uses Windows CapabilityAccessManager ConsentStore notifications with zero background polling (0% CPU at rest).
- **Dynamic Eyes with Randomized Expressions:** The idle "Eyes" look (`IdleStyle::Eyes`) now features rich, randomized emotional expressions during rest: blink, flutter, squint, smile, sleep, sly glance, reading motion, and thinking look.
- **Idle Glove Wave Animation:** After 30 seconds of user cursor inactivity, the island smoothly expands to 160 px and a pair of friendly cartoon gloves wave for 2.5 seconds before resting. Moving the cursor instantly cancels waving.
- **Battery Status Line Indicator:** An optional 2px subtle status line at the very bottom edge of the island dynamically reflects real laptop battery percentage (Green $>50\%$, Yellow $16-50\%$, Red $\le 15\%$). Automatically hidden on desktop PCs without batteries.
- **Appearance Settings Toggles:** Configure both features easily in Settings under the Appearance tab: "Privacy indicator" (default: On) and "Battery status line" (default: Off).

**Install:** Download `Oyenza-Studio-Setup-1.2.1.exe` and run it. It installs per-user (no administrator rights needed) and can start with Windows.
