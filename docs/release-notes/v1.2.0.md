# Oyenza Studio v1.2.0

**Calendar Island Countdown & Event Notifications:**
- **3-Minute Event Countdown (`Activity::Calendar`):** When an upcoming scheduled event is within 3 minutes (configurable in Settings), the closed island pill shows a calendar icon, the event name (or event count if multiple events overlap), minutes left, and an inline `[OK]` pill.
- **Dismissible with `[OK]`:** Clicking `[OK]` puts the countdown away until the event begins, restoring your idle clock or media playback.
- **Direct Navigation:** Clicking the pill body immediately opens the **Today** page in the expanded island with event details.
- **Chimes & Start Notice:** Plays a gentle chime when entering the 3-minute countdown window, and shows an event start notice pop-up with a chime when the event begins.
- **Configurable Settings:** Adjustable in Settings under Popups > Calendar countdown (0 = Off, 1..60 min, default 3 min).

**Install:** Download `Oyenza-Studio-Setup-1.2.0.exe` and run it. It installs per-user (no administrator rights needed) and can start with Windows.
